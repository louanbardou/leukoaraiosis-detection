# Leukoaraiosis Detection — Quick Start

## Before uploading: prepare labels.csv

Create a CSV file named `labels.csv` with the following three columns:

```
subject_id,session,label
sub-0DBRJXKG,ses-00A,0
sub-NDARINV0001,ses-00A,1
```

Column definitions:

- `subject_id`: matches the folder name under the mproc imaging root (e.g. `sub-0A4P0LWM`).
  The `sub-` prefix is optional; the script adds it automatically.
- `session`: ABCD session identifier (ses-00A through ses-06A).
  The `ses-` prefix is optional.
- `label`: 1 if leukoaraiosis is present (clfind_score >= 3 in the ABCD
  clinical findings table), 0 otherwise.

Place `labels.csv` inside the `Leuko_abcd/` folder before uploading.

```bash

cd /mnt/fac/CX500007_DS1/bardou/leukoaraiosis-detection/Leuko_abcd
```

## Step 3: Build the manifest (login node, roughly 5 minutes)

```bash
python phase1_2_build_manifest.py \
    --labels    labels.csv \
    --data_root /mnt/fac/CX500007_DS1/ABCD/6.1/imaging/derivatives/mproc \
    --out_csv   manifest.csv
```

Expected output:
- Approximately 12,000 to 15,000 rows total
- Approximately 500 to 700 positive rows (label=1)

If many rows are dropped, verify that subject IDs in `labels.csv` match the
folder names under `mproc/` exactly (e.g. `sub-0A4P0LWM`).

## Step 4: Verify the transform pipeline (login node, CPU)

```bash
python -c "

df = pd.read_csv('manifest.csv').head(1)
t = get_val_transforms()

```

Expected output: `torch.Size([2, 96, 96, 96])`.

---

## Step 5: Submit the training job (SLURM)

```bash
mkdir -p logs
sbatch jobs/train_phase3.sh
```

Monitor progress:

```bash
squeue -u $USER
tail -f logs/train_*.out
```

Training runs for 100 epochs (~24–40 hours on a single A100).
Best checkpoint saved to `runs/phase3_YYYYMMDD_HHMMSS/best_model.pt`.

---

## Step 6: Generate Grad-CAM heatmaps (after training)

1. Edit `jobs/gradcam_phase4.sh` → fill in `CHECKPOINT`.
2. Submit:
   ```bash
   sbatch jobs/gradcam_phase4.sh
   ```
3. Heatmaps saved to `heatmaps/gradcam_YYYYMMDD/`.

## Step 7: Pseudo-mask self-training (optional, Phase 5)

Run only if Phase 3 AUPREC > 0.60.

1. Edit `jobs/train_phase5.sh` → fill in `CHECKPOINT` and `HEATMAP_DIR`.
2. Submit:
   ```bash
   sbatch jobs/train_phase5.sh
   ```
3. Best segmentation model saved to `runs/phase5/best_segmodel.pt`.

## Key hyperparameters

| Parameter | Value | Rationale |
|---|---|---|
| patch_size | 96 x 96 x 96 | Covers periventricular and subcortical white matter at 1 mm isotropic |
| feature_size | 48 | ~62M parameters; fits A100 80 GB with gradient checkpointing |
| batch_size | 4 | Safe VRAM budget with use_checkpoint=True |
| learning rate | 1e-4 | SOAP default; stable with APLoss |
| APLoss margin | 1.0 | Standard squared-hinge margin for AUPREC optimisation |
| cross-validation | StratifiedGroupKFold k=5 | Group by subject to prevent session-level data leakage |
