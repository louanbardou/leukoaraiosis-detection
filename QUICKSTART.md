# Leukoaraiosis Detection — Quick Start

## Before uploading: prepare labels.csv

Create a CSV file named `labels.csv` with the following three columns:

```
subject_id,session,label
sub-0DBRJXKG,ses-00A,0
sub-NDARINV0001,ses-00A,1
```

Column definitions:

- `subject_id`: matches the folder name under the mproc imaging root.
  The `sub-` prefix is optional; the script adds it automatically.
- `session`: ABCD session identifier (ses-00A through ses-06A).
  The `ses-` prefix is optional.
- `label`: 1 if leukoaraiosis is present (clfind_score >= 3 in the ABCD
  clinical findings table), 0 otherwise.

Place `labels.csv` inside the `Leuko_abcd/` folder before uploading.

## Step 3: Build the manifest (login node, roughly 5 minutes)

```bash
python phase1_2_build_manifest.py \
    --labels    labels.csv \
    --data_root /wynton/group/abcd/6.0/imaging/derivatives/mproc \
    --out_csv   manifest.csv
```

Expected output:
- Approximately 12,000 to 15,000 rows total
- Approximately 500 to 700 positive rows (label=1)

If many rows are dropped, verify that the subject IDs in `labels.csv` match
the folder names under the mproc root exactly.

---

## Step 4: Verify the transform pipeline (login node, CPU)

This step runs one sample through the preprocessing pipeline to confirm that
everything loads correctly before submitting a GPU job.

```bash
python -c "
from phase1_3_transforms import get_val_transforms
import pandas as pd
df = pd.read_csv('manifest.csv').head(1)
t = get_val_transforms()
d = t({'t1w': df.t1w_path[0], 't2w': df.t2w_path[0]})
print('Image shape:', d['image'].shape)
"
```

The expected output is `torch.Size([2, 96, 96, 96])`.

---

## Step 5: Submit the training job (SLURM)

```bash
mkdir -p logs
sbatch jobs/train_phase3.sh
```

Monitor progress:

```bash
squeue -u $USER
tail -f logs/train_*.out
```

Training runs for 100 epochs and takes roughly 24 to 40 hours on a single A100.
The best checkpoint is saved to `runs/phase3_YYYYMMDD_HHMMSS/best_model.pt`
whenever validation AUPREC improves.

---

## Step 6: Generate Grad-CAM heatmaps (after training)

1. Edit `jobs/gradcam_phase4.sh` and fill in the `CHECKPOINT` variable with
   the path to your best_model.pt.
2. Submit the job:
   ```bash
   sbatch jobs/gradcam_phase4.sh
   ```
3. Per-subject heatmaps are saved as `.nii.gz` files in `heatmaps/gradcam_YYYYMMDD/`.
4. The aggregate heatmap across all true-positive subjects is saved as
   `aggregate_gradcam_positives.nii.gz` in the same directory.

---

## Step 7: Pseudo-mask self-training (optional, Phase 5)

Run this step only if Phase 3 validation AUPREC exceeded 0.60.

1. Edit `jobs/train_phase5.sh` and fill in both `CHECKPOINT` and `HEATMAP_DIR`.
2. Submit the job:
   ```bash
   sbatch jobs/train_phase5.sh
   ```
3. The script converts heatmaps to binary masks (Otsu thresholding) and then
   fine-tunes the full Swin UNETR decoder with DiceFocalLoss.
4. The best segmentation model is saved to `runs/phase5/best_segmodel.pt`.

## Key hyperparameters

| Parameter | Value | Rationale |
|---|---|---|
| patch_size | 96 x 96 x 96 | Covers periventricular and subcortical white matter at 1 mm isotropic |
| feature_size | 48 | Approximately 62 million parameters; fits A100 80 GB with gradient checkpointing |
| batch_size | 4 | Safe VRAM budget with use_checkpoint=True |
| learning rate | 1e-4 | SOAP default; stable with APLoss |
| APLoss margin | 1.0 | Standard squared-hinge margin for AUPREC optimisation |
| cross-validation | StratifiedGroupKFold k=5 | Group by subject to prevent session-level data leakage |
