Problem Definition
What are we trying to detect, and why is it hard?
🧠
Leukoaraiosis
White matter hyperintensities (WMH) visible on T2/FLAIR MRI. Diffuse, bilateral lesions — not a single focal point. Linked to cerebrovascular disease and cognitive decline.
👶
ABCD Dataset
Adolescent Brain Cognitive Development study. ~11,000 subjects, multi-site (21 scanners), T1w + T2w available. Leukoaraiosis rare in this age group (~3–5% positive).
⚠️
Core Challenges
1. Class imbalance — ~95% negative
2. No voxel masks — only image-level labels
3. Multi-site variability — 21 different scanners
4. 3D volumetric data — memory constraints
🔑
Key Constraint #1 — Label Type
We only have image-level binary labels (positive / negative). No voxel-level annotations. Any architecture must work under this weak supervision regime.
🔑
Key Constraint #2 — Class Imbalance
Standard accuracy is meaningless. A model that always predicts "negative" achieves ~97% accuracy. We must optimize for minority-class detection.

Preprocessing Pipeline
Every step exists for a specific scientific reason
1
Orientation → RAS (Right-Anterior-Superior)
ABCD data comes from 21 sites with different scanner orientations. Without standardization, "left" in one scan is "right" in another — the model would learn inconsistent anatomy.

RAS is the canonical neuroimaging convention. All scans are reoriented to match it before any other operation.
2
Resampling → 1 mm Isotropic
Scanners produce different voxel sizes (e.g. 1×1×1.2 mm, 0.8×0.8×0.8 mm). If T1w and T2w are on different grids, channel concatenation would be misaligned.

Resampling to a common 1 mm grid ensures voxel-exact alignment between T1 and T2 channels. It also means 1 voxel = 1 mm³, enabling direct volume estimation in Phase 4/5.
Spacingd(keys=["t1w", "t2w"], pixdim=(1.0, 1.0, 1.0), mode="bilinear")
3
Two-Step Intensity Normalization
Step A — Percentile Clipping [1st, 99th] → [0, 1]
MRI images have scanner-specific outlier intensities (bright eyeballs, RF coil hotspots) that would dominate gradient updates. Clipping outside the 1st–99th percentile range removes these before normalizing.
Percentile Clipping
\[ x_{\text{clipped}} = \text{clip}\!\left(\frac{x - p_1}{p_{99} - p_1},\ 0,\ 1\right) \]
where \(p_1\) and \(p_{99}\) are the 1st and 99th percentile of voxel intensities. Outliers above \(p_{99}\) are clamped to 1; below \(p_1\) are clamped to 0.
Step B — Z-score per channel
T1w and T2w intensities live on completely different scales (T1: bright = fat/white matter; T2: bright = fluid). Z-scoring each channel independently makes them comparable for the network.
Z-score Normalization
\[ x_{\text{norm}} = \frac{x - \mu_{\text{channel}}}{\sigma_{\text{channel}}} \]
Applied channel-wise and non-zero only — background voxels (value = 0) are excluded from mean/std computation to avoid bias from the skull-stripped background.
4
Foreground Crop → Patch Extraction 96×96×96
Full brain volumes are ~180×220×180 voxels — far too large to fit in GPU memory.

CropForeground removes air voxels around the skull (T1w-guided), reducing volume to ~150³. RandSpatialCrop then extracts a fixed 96³ patch — randomly during training, centered during validation.
💾
Memory Constraint → Patch Size = 96³
The Swin UNETR processes fixed-size inputs. At batch size 4 with 96³ patches, peak VRAM is ~38 GB on an A100. Full volume (180³) would require ~2 TB — infeasible.
5
Data Augmentation (Training Only)
Spatial: random flips (p=0.5), 90° rotations (p=0.5), affine transforms (p=0.3 — moderate to avoid extreme distortions).

Intensity: Gaussian noise (p=0.2, σ=0.05), Gaussian blur (p=0.2), random intensity scaling (p=0.3, ±10%).

These simulate scanner-to-scanner variability. The model learns anatomy, not scanner signatures.
4
Model Architecture
From all possible model families down to Swin UNETR
Level 1 — ML Paradigm
Classical ML (SVM, RF)
Requires hand-crafted features (texture, volume). Cannot learn spatial patterns end-to-end. Fails on raw 3D voxels.
Deep Learning
Learns hierarchical spatial features automatically. State-of-the-art on medical imaging benchmarks. End-to-end from raw voxels to prediction.
▼
Level 2 — Dimensionality
2D Slice-by-Slice
Loses inter-slice context. Leukoaraiosis is a volumetric phenomenon — 2D slices miss continuity across the z-axis.
2.5D (multi-slice)
Partial improvement but still treats z-axis as a stack, not a continuum. Asymmetric receptive fields.
Full 3D Volumetric
Brain is a 3D structure. White matter tracts span all axes. A 3D model captures the full spatial extent of diffuse WMH.
▼
Level 3 — Feature Extraction Mechanism
3D CNN (e.g. ResNet-3D)
Local convolutional kernels. Good for focal lesions. Limited receptive field — cannot model long-range dependencies across white matter tracts without very deep stacks.
Standard ViT (3D)
Full self-attention has O(T²) complexity. For 96³ voxels with patch size 4, T = 13,824 tokens → quadratic cost is prohibitive.
Swin Transformer (3D)
Windowed self-attention — linear complexity in volume size. Shifted windows propagate global context across layers. Designed for hierarchical feature extraction at multiple scales.
⚡
Why Transformers over CNNs for WMH?
Leukoaraiosis is diffuse — lesions appear across periventricular and deep white matter simultaneously. Standard CNNs process local patches; a kernel of size 3³ sees 27 voxels. White matter tracts span hundreds of voxels. Swin Transformers compute attention within windows and shift those windows between layers, building global context incrementally.
Swin Self-Attention Complexity
\[ \Omega(\text{MSA}) = 4hwC^2 + 2(hw)^2C \qquad \text{(standard ViT: } O(T^2) \text{)} \] \[ \Omega(\text{W-MSA}) = 4hwC^2 + 2M^2 hwC \qquad \text{(Swin: } O(T) \text{)} \]
where \(h \times w\) = spatial resolution, \(C\) = channels, \(M\) = window size. Swin's complexity is linear in the number of tokens \(T = hw\), not quadratic. For 96³ volume this is the difference between feasible and infeasible.
▼
Level 4 — Specific Architecture Variant
Swin-B / Swin-L (pure encoder)
Classification only — cannot be extended to segmentation later. Would require full retraining for Phase 5.
TransUNet / SETR
Hybrid CNN-Transformer. Good for 2D, not natively designed for 3D. Less established in volumetric medical imaging.
Swin UNETR
Swin encoder + UNETR decoder. The encoder can be used alone for classification (Phases 3–4) and the decoder activated for segmentation (Phase 5) — no weight surgery needed.
The Decoder Investment

The full Swin UNETR is instantiated (encoder + decoder) even in Phases 3 and 4 where the decoder is unused. This is intentional: Phase 5 reuses the same object and activates the decoder with the encoder weights already trained. No restructuring, no re-loading. The decoder is a "free option" — zero extra cost during classification, full value during segmentation.

Classification Head Design Choices

ComponentChoiceWhy not the default?
Normalization LayerNorm BatchNorm degrades at small batch sizes (B=4 with 3D volumes). LayerNorm normalizes per-sample, not per-batch — stable regardless of batch size.
Activation GELU ReLU has a hard zero at x<0 (dying neurons). GELU is smooth near zero — \(\text{GELU}(x) = x \cdot \Phi(x)\) — better gradient flow during early epochs with random weights.
Output Raw logit (no sigmoid) APLoss and BCEWithLogitsLoss operate on logits directly. Applying sigmoid inside forward() would force manual unwrapping in the loss — error-prone.
Dropout p=0.3 → p=0.15 Heavier dropout after the large 1536-dim layer, lighter before the final projection. Reduces co-adaptation without starving the 256-dim layer of signal.
GELU vs ReLU
\[ \text{ReLU}(x) = \max(0, x) \qquad\qquad \text{GELU}(x) = x \cdot \Phi(x) \approx x \cdot \sigma(1.702\, x) \]
where \(\Phi\) is the CDF of the standard normal. ReLU's derivative is 0 for \(x < 0\), killing neurons permanently. GELU's derivative is smooth and nonzero even slightly below zero — neurons stay "alive" and continue receiving gradient signal.
💾
use_checkpoint=True — Gradient Checkpointing
During backpropagation, PyTorch normally stores all intermediate activations from the forward pass in memory. For Swin UNETR processing 96³ volumes, this exceeds A100 VRAM at batch size 4. Gradient checkpointing recomputes activations on-the-fly during backprop instead of storing them — trading ~30% extra compute for ~40% VRAM reduction.
5
Supervision Strategy
No voxel masks → weak supervision via Global Average Pooling
Supervision Paradigm Options
Fully Supervised Segmentation
Requires per-voxel masks annotated by radiologists. Not available in ABCD. Extremely expensive to obtain for 11,000 subjects.
Self-Supervised (MAE, contrastive)
Good for pretraining but doesn't directly optimize for leukoaraiosis detection. Needs a downstream fine-tuning step anyway.
Weakly Supervised (image-level labels)
Use existing clinical binary labels (positive/negative). GAP + classification head forces the encoder to localize lesions to make correct predictions — no voxel labels needed.
How GAP Creates Implicit Localization

Global Average Pooling collapses (B, C, D, H, W) → (B, C, 1, 1, 1). Each channel's single scalar = average activation across the entire volume. For the classifier to predict "positive", it must produce high activations in the channels that respond to lesion patterns. This constraint forces the encoder to learn spatially discriminative features — which Grad-CAM can then reveal.

Global Average Pooling
\[ z_c = \frac{1}{D \cdot H \cdot W} \sum_{d,h,w} A_c(d, h, w) \]
where \(A_c\) is the activation map for channel \(c\) at the bottleneck. The resulting vector \(\mathbf{z} \in \mathbb{R}^{1536}\) feeds the classification head. No spatial information is preserved — but during Grad-CAM, we bypass GAP and read \(A_c\) directly to recover spatial heatmaps.

Loss Function & Optimizer
The hardest decisions — class imbalance forces non-standard choices

Step 1 — Choose the Right Evaluation Metric

MetricWhat it measuresProblem with imbalanced data
Accuracy % correct predictions ✗ Predict all-negative → 97% accuracy. Useless.
AUROC Rank positives above negatives ✗ Penalized by True Negative Rate — trivially high when predicting mostly negative.
AUPREC Precision-Recall tradeoff for positives ✓ Completely insensitive to negative class size. Honest measure of minority-class detection.
Precision-Recall vs ROC
\[ \text{Precision} = \frac{TP}{TP + FP} \qquad \text{Recall} = \frac{TP}{TP + FN} \] \[ \text{AUPREC} = \int_0^1 \text{Precision}(r)\, dr \]
AUPREC only involves TP, FP, FN — the True Negatives (the majority class) do not appear. With 95% negatives, AUROC is dominated by how well the model handles the easy majority. AUPREC forces the model to care about the rare positives.

Step 2 — Make AUPREC Differentiable

🚧
Problem: AUPREC is not differentiable
AUPREC is computed from a sorted ranking of predictions. Sorting is a discrete, non-differentiable operation — you cannot backpropagate through it directly. We need a smooth surrogate.
Loss Function Options for Imbalanced Classification
Binary Cross-Entropy
Each sample contributes equally. 95% of gradient comes from negatives → model ignores positives.
Focal Loss
Down-weights easy negatives. Better, but still optimizes per-sample probability, not the ranking that AUPREC measures.
Weighted BCE
Manual weight tuning needed. Fragile across folds with different imbalance ratios.
APLoss (Average Precision Loss)
Smooth surrogate for AUPREC via squared-hinge relaxation of the pairwise ranking objective. Directly optimizes what we measure.
APLoss — Pairwise Ranking Objective
\[ \mathcal{L}_{\text{AP}} = \sum_{i \in \mathcal{P}} \sum_{j \in \mathcal{N}} \ell\!\left(s_i - s_j\right) \] \[ \ell(z) = \max(0,\; 1 - z)^2 \quad \text{(squared-hinge)} \]
For every pair (positive \(i\), negative \(j\)), the loss penalizes cases where the positive score \(s_i\) does not exceed the negative score \(s_j\) by at least the margin (=1). The squared-hinge makes the loss smooth and differentiable. The gamma=0.1 parameter applies a moving average to stabilize gradient estimates across batches.

Step 3 — Optimizer Coupled to the Loss

Optimizer Options
Adam + APLoss
Adam treats APLoss like any other loss. The pairwise ranking objective has non-i.i.d. structure across batches — Adam ignores this and produces unstable training.
AdamW + APLoss
Same issue as Adam. Weight decay helps with regularization but doesn't address the non-i.i.d. structure of pairwise losses.
SOAP (LibAUC)
SOAP (Stochastic Optimization for Average Precision) maintains an internal surrogate state coupled to APLoss. Specifically designed for pairwise ranking — epoch_decay anneals the regularization term progressively.

Step 4 — Preventing Data Leakage in Cross-Validation

Cross-Validation Strategy
KFold
Random split. Two sessions from the same subject could land in train AND validation. The model memorizes subject anatomy → inflated metrics.
StratifiedKFold
Preserves class ratios but still allows same-subject leakage across folds.
StratifiedGroupKFold
Groups = subject_id. All sessions from one subject go entirely into one fold. Stratification ensures ~equal positive ratio per fold. Prevents subject-level leakage.
Why Subject Leakage Is Dangerous

ABCD has multiple sessions per subject. If sessions from the same subject appear in both train and validation, the model learns who the person is rather than what the lesion looks like. Validation AUPREC would be inflated because the model recognizes subject-specific brain anatomy, not disease patterns.

Explainability — Grad-CAM
Recovering spatial heatmaps from a classification model
Why Grad-CAM and not alternatives?

We need spatial heatmaps to (1) validate the model is attending to white matter, not artifacts, and (2) generate pseudo-masks for Phase 5. Grad-CAM works on any pretrained model without retraining. Alternatives like LIME or SHAP are too slow for 3D volumes. Attention rollout requires transformer-specific hooks that are harder to implement across all Swin stages.

Grad-CAM Algorithm (3D)

Step 1 — Forward pass; capture activation tensor at target layer:

\[ A \in \mathbb{R}^{B \times C \times D' \times H' \times W'} \]

Step 2 — Backpropagate the positive-class logit; capture gradient tensor:

\[ G = \frac{\partial s_{\text{pos}}}{\partial A} \in \mathbb{R}^{B \times C \times D' \times H' \times W'} \]

Step 3 — Per-channel importance weights via global average pooling over spatial dims:

\[ \alpha_c = \frac{1}{D' H' W'} \sum_{d,h,w} G_c(d, h, w) \]

Step 4 — Weighted combination of activation maps + ReLU:

\[ \text{CAM} = \text{ReLU}\!\left(\sum_c \alpha_c \cdot A_c\right) \]

Step 5 — Upsample from encoder resolution to 96³ via trilinear interpolation; normalize to [0,1].

ReLU removes channels that suppress the positive prediction. Only regions that positively contribute to the leukoaraiosis score are highlighted.
🔧
Swin Transformer Token Reshaping
Standard CNNs produce spatial tensors (B, C, D, H, W). Swin Transformers output token sequences (B, T, C). Before computing the weighted sum, the sequence is reshaped to spatial: T → (D', H', W') by taking the cube root of T (valid because the input is isotropic and windows are cubic). Without this step, Grad-CAM would produce a meaningless 1D heatmap.
🎯
Target Layer: layers4[-1] (last block, deepest stage)
Earlier layers capture local texture (edges, intensities). Deeper layers capture semantic, abstract features — "this region looks like white matter with pathological changes". The last block of the deepest Swin stage (layers4) has the largest receptive field and most globally abstract representations. It produces the most meaningful Grad-CAM heatmaps for diffuse lesion localization.

Phase 5 — Pseudo-Mask Self-Training
From coarse heatmaps to voxel-level segmentation, without manual annotations
A
Otsu Thresholding → Pseudo-Masks
Grad-CAM heatmaps are continuous (0–1). We need binary masks to train a segmentation model. Manual threshold tuning is fragile — Otsu's method automatically finds the optimal threshold by maximizing inter-class variance between background and lesion intensity distributions.
Otsu's Method
\[ \sigma^2_{\text{between}}(t) = w_0(t)\, w_1(t)\, \bigl[\mu_0(t) - \mu_1(t)\bigr]^2 \] \[ t^* = \arg\max_t\; \sigma^2_{\text{between}}(t) \]
where \(w_0, w_1\) are the proportions of voxels below/above threshold \(t\), and \(\mu_0, \mu_1\) are their means. Computed on nonzero voxels only — the large zero-background would bias the threshold toward zero. Only heatmaps with ≥100 nonzero voxels are processed (too few = classifier found no clear evidence of pathology).
B
Decoder Fine-Tuning with DiceFocalLoss
The UNETR decoder (randomly initialized) is fine-tuned using pseudo-masks as supervision. The encoder weights from Phase 3 are frozen at first — a low learning rate (5×10⁻⁵ vs 10⁻⁴ in Phase 3) avoids disrupting the representations already learned.
DiceFocalLoss = Dice Loss + Focal Loss
\[ \mathcal{L}_{\text{Dice}} = 1 - \frac{2 \sum_i p_i g_i}{\sum_i p_i + \sum_i g_i} \] \[ \mathcal{L}_{\text{Focal}} = -\sum_i (1-p_i)^\gamma \log p_i \] \[ \mathcal{L}_{\text{total}} = \lambda_{\text{Dice}}\,\mathcal{L}_{\text{Dice}} + \lambda_{\text{Focal}}\,\mathcal{L}_{\text{Focal}} \quad (\lambda=1 \text{ each}) \]
Dice is invariant to lesion size — it measures overlap regardless of whether the lesion is 10 voxels or 10,000. Critical for imbalanced segmentation (lesion << background).

Focal with γ=2 down-weights easy voxels: for p=0.9 → weight = (1−0.9)² = 0.01; for p=0.5 → weight = 0.25. Hard boundary voxels receive 25× more gradient signal than confidently-classified interior voxels.
Why Self-Training Works Here

Phase 3 achieved high AUPREC — the classifier knows where leukoaraiosis is (it just can't tell us at the voxel level). Grad-CAM reveals those regions coarsely. By treating these coarse outlines as ground truth, we train the decoder to produce precise voxel-level maps. This is label propagation: weak image-level labels → coarse spatial labels → precise segmentation masks. Each step refines the previous without requiring any manual annotation.
